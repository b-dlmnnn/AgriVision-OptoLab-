# AgriVision OptoLab: Opto-Mechatronic Agricultural Quality & IoT System

An end-to-end Computer Vision, Machine Learning, and IoT Telemetry prototype designed for automated agricultural product quality grading and biological monitoring workflows.

## Key Capabilities
- Optical Produce Grading (OpenCV + Random Forest): Extracts HSV color descriptors, surface blemish area ratio, and Canny edge density to classify agricultural produce.
- Configurable Quality Gate Controls: Real-time tolerance sliders for maximum allowable blemish percentage and classifier confidence thresholds.
- IoT & Environmental Telemetry Sync: Interactive time-series visualization tracking greenhouse temperature, relative humidity, and optical Grade-A yield correlations.
- Automated Lab Reporting: One-click CSV inspection report export for quality traceability.

## Tech Stack
- Language & Web App: Python, Streamlit
- Computer Vision & ML: OpenCV, scikit-learn, NumPy, pandas
- Visualization: Plotly
